# Renewal 디자인 시스템 (Claude용 규칙 · 사람도 읽을 수 있음)

> 이 폴더로 만드는 대시보드는 **모두 같은 디자인 언어**를 쓴다. 업종·화면 구성은 학생마다 달라도
> 색·글자·간격·부품 모양은 여기 규칙을 따른다. 실제 값은 [`globals.css`](./globals.css) 가 정본이다.
> 완성 모습은 `reference/` 예시에서 확인한다.

## 0. 적용 방법 (STEP 1 에서 한 번)

1. shadcn init 이 만든 `src/app/globals.css` 를 **`design/globals.css` 내용으로 통째로 교체**한다.
   shadcn init 은 반드시 임시 폴더(`scaffold-tmp`) 안에서 돌린다 — 루트에서 돌리면 이 폴더의 `globals.css` 를 덮어쓴다 (MASTER-PLAN STEP 1).
2. `src/app/layout.tsx` 의 `<head>` 에 Pretendard 를 넣고, Geist 등 다른 글꼴은 지운다.
   ```html
   <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css" />
   ```
3. ThemeProvider 는 `attribute="class"`, `defaultTheme="light"`, `enableSystem={false}`.
4. `components/ui/`(shadcn 생성물)는 고치지 않는다. 모양 보정은 `globals.css` 맨 아래 "원자 보정"이 맡는다.

## 1. 원칙

1. **강조색은 파랑 하나.** 선택·활성·켜짐·포커스·링크·오늘 날짜 = `primary`. 보라·주황·그라디언트 강조 금지.
   상태색(성공·경고·위험)은 **상태 표시에만** 쓴다(선택 표시에 쓰지 않는다).
2. **글자는 진하고 또렷하게.** Pretendard, 본문 굵기 500. 본문에 `text-meta`(가장 옅은 회색) 금지 — 시간·건수 전용.
3. **위계 4단계 고정:** 페이지 제목 → 섹션·카드 제목 → 본문 → 보조·메타.
4. **여백은 4px 단위**(4/8/12/16/20/24/32). 카드 안쪽 20, 카드 사이 16, 페이지 머리 아래 24.
5. **설명 문구를 늘어놓지 않는다.** 화면 부제·안내 박스 대신 필요한 곳에만 짧은 보조 문구나 툴팁.
   단 상태 안내(빈 상태·오류·"새로고침하면 초기화" 같은 한계 안내)는 남긴다.
6. **같은 요소는 모든 화면에서 같은 모양.** 화면마다 일회성 색·크기를 만들지 않는다.
7. **화면 코드에 `#hex`·`rgb()` 직접 쓰기 금지.** 전부 토큰(Tailwind 클래스 또는 `var(--…)`). 예외는 구글 로고 4색뿐.

| 카드·패널 | `bg-card` | #FFFFFF | #0D151D |
| 표 머리·섹션 머리 | `bg-surface-2` | #F9F9FB | #0A1118 |
| 제목·강조 글자 | `text-foreground` | #171719 | #D7DFEA |
| 보조 글자 | `text-muted-foreground` | #5A6070 | #8A98AE |
| 메타(시간·건수) | `text-meta` | #6F7682 | #7E8EA5 |
| 구분선·카드 테두리 | `border-border` | #E6E8EC | #202C3D |
| 입력·보조 버튼 테두리 | `border-line-strong` | #D5D8DE | #35455D |

| 위험 | `text-destructive` `bg-danger-soft` | #E5383B / #FDEFEF | #F07178 / 14% |

**차트 5색** `--chart-1`~`--chart-5`: 파랑 · 주황 · 청록 · 보라 · 분홍 (색약 검사 통과 순서).
1번부터 순서대로 쓰고 돌려쓰지 않는다. 6번째 계열이 필요하면 "기타"로 묶는다. 상태(초과·위험)는 `--destructive`.
계열이 2개 이상이면 범례를 꼭 둔다(색만으로 구분하지 않는다). 축·격자는 `--border`·`--muted-foreground`.

## 3. 글자 위계

| 단계 | 크기/굵기/행간 | 클래스 | 쓰임 |
|---|---|---|---|
| 페이지 제목 | 24 / 700 / 32 | `.t-title` | 화면 h1 (페이지마다 하나) |
| 섹션 제목 | 18 / 700 / 26 | `.t-section` | 드로어 제목, 큰 블록 제목 |
| 카드 제목 | 16 / 600 / 24 | `.t-card` | 카드 머리 (`CardTitle` 은 자동) |
| 본문 | 14 / 500 / 22 | (기본) | 대부분의 글자 |
| 보조 | 13 / 500 / 20 | `.t-sub` | 설명·보조 값·표 셀 |
| 메타 | 12 / 500 / 18 | `.t-meta` | 시간·건수·칩 |

11px 이하 글자는 쓰지 않는다(배지 예외). 숫자는 전역 고정폭(tabular-nums)이라 따로 지정하지 않아도 된다.
`.t-*` 클래스는 Tailwind 유틸보다 약하다. shadcn 의 `CardTitle`·`SheetTitle`·`DialogTitle` 처럼 이미 글자 크기 유틸이 붙은 부품에는
`.t-*` 대신 유틸을 직접 쓴다(예: 드로어 제목 `text-lg leading-[26px] font-bold tracking-tight`).

## 4. 부품(원자)

- **버튼**: shadcn `Button`. 주 버튼 = 파랑 채움(화면당 1개), 보조 = `variant="outline"`, 아이콘만 = `variant="ghost" size="icon"`.
- **입력·셀렉트**: shadcn `Input`·`Select`. 포커스 = 파랑 테두리 + 옅은 파랑 링(자동).
- **카드**: shadcn `Card` — 흰 바탕, 1px 선, 옅은 그림자, 모서리 16, 안쪽 20 (자동). 카드 안에 카드를 또 넣지 않는다.
- **표**: 머리 = `bg-surface-2` 13/600, 행 높이 48~52, 세로선 없음, 가로선 `border-border`, 행 hover `hover:bg-hover`,
  선택 행 `bg-brand-softer`. 긴 글자는 말줄임(`truncate`). 숫자 열은 오른쪽 정렬.
- **배지·칩**: 모서리 4, 12/600. 상태 배지 = 상태색 soft 바탕 + 상태색 글자. 분류 배지 = `bg-muted text-muted-foreground`.
  선택된 필터 칩만 `bg-brand-soft text-brand-ink`.
- **세그먼트(보기 전환·기간 토글)**: 바탕 `bg-muted` 모서리 8 안쪽 2, 선택 항목 = `bg-card` + 그림자 + `text-primary` 600.
- **빈 상태**: 카드 가운데 아이콘(옅은 회색 원) + 한 줄 제목 + 한 줄 안내 + (있으면) 행동 버튼 하나.
- **토스트**: sonner, 화면 위 가운데. 저장·삭제·복원 성공을 짧게 알린다.

## 5. 셸 (모든 화면 공통 틀)

```
┌────────────┬──────────────────────────────────────────────┐
│ ■ 이름      │ (헤더 56) ☰(모바일)            ☀/☾  (프로필) │
│            ├──────────────────────────────────────────────┤
│ 워크스페이스 │  페이지 제목 24/700          [주요 버튼]      │
│  ▣ 홈       │                                              │
│  ▣ 킬러     │  (본문 — 최대 폭 1440, 좌우 24)               │
│  ▣ …       │                                              │
│ 지식·문서    │                                              │
│  ▣ 위키     │                                              │
│  ▣ 문서 관리 │                                              │
│ ─────────  │                                              │
│  ▣ 설정     │                                              │
└────────────┴──────────────────────────────────────────────┘
```

- **사이드바**: 폭 224, `bg-sidebar` + 오른쪽 1px 선. 맨 위 = 로고 마크 24 + 서비스 이름 16/700.
  메뉴는 **그룹**으로 묶는다: 그룹 이름 12/600 `text-muted-foreground`. 항목 높이 40, 모서리 8, 아이콘 20 + 14/500.
  **활성 = `bg-sidebar-accent` + `text-sidebar-accent-foreground` 600** (파랑 연한 바탕 + 파랑 글자). hover = `bg-hover`.
  설정은 맨 아래(그룹 밖)에 둔다. 1024px 미만에서는 숨기고 헤더 ☰ 버튼이 같은 메뉴를 시트로 연다.
- **헤더**: 높이 56, `bg-card` 불투명 + 아래 1px 선. 경로 표시·제목을 넣지 않는다(현재 위치는 사이드바 활성 표시로).
  오른쪽 = 테마 전환 · 프로필 메뉴(이름·이메일·로그아웃).
- **페이지 머리**: 모든 화면 맨 위 `PageHeader` — h1(24/700) + 오른쪽 주요 버튼. 부제는 꼭 필요할 때만 한 줄(13/500).

## 6. 드로어(오른쪽 패널) 두 가지

- **조회 드로어** (킬러 모듈 상세, 문서 미리보기): shadcn `Sheet side="right"`, 폭 `min(560px, 92vw)`.
  머리 = 아이콘 타일 40(파랑 soft) + 제목 18/700 + 메타 한 줄 / 본문 = 섹션 카드 나열.
- **작업 드로어** (위키 편집처럼 입력이 있는 것): 같은 Sheet, 폭 `min(720px, 94vw)`. 입력은 2열 격자,
  저장 버튼은 드로어 아래 오른쪽. 변경이 없으면 저장 비활성.

## 7. 화면별 배치 규칙

- **홈**: KPI 카드 4개(한 줄) → 킬러 모듈 요약 카드(TOP 5) → 모듈 바로가기 카드 → 최근 위키·최근 문서.
- **킬러 모듈**: 요약 숫자 카드 → 기준 조절 줄(슬라이더/셀렉트, 카드 위 한 줄) → 분포 차트 → 목록 → 클릭 시 조회 드로어.
- **위키**: 왼쪽 카테고리 목록(폭 240, "전체"+카테고리별 개수) | 오른쪽 = 검색·태그 칩 줄 + 문서 카드 목록.
  문서를 누르면 오른쪽 조회 드로어에 본문(마크다운)을 연다. [새 문서]는 작업 드로어.
- **문서 관리(업무폴더)**: 맨 위 도구 줄 = `↑`(상위 폴더) · 경로 상자 · 파일 검색 · [새 폴더] · [휴지통] · [올리기].
  본문 카드 하나를 좌우로 나눈다: 왼쪽 폴더 트리(폭 280, 맨 위 "업무폴더 N" 루트, 펼침 화살표) |
  오른쪽 목록 표(이름 ↑ · 출처 · 수정일 · 크기·항목 · ⋯). 폴더 행을 누르면 들어가고, 파일 행을 누르면 미리보기 드로어.
- **설정**: 폭 672 가운데 정렬 카드 나열 — 테마 · 기준값 · 계정(로그아웃) · 정보.
